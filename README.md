# John Idowu — DevOps Portfolio

A responsive, static portfolio website for John Idowu, focused on DevOps, cloud
engineering, and scalable technology solutions.

## Run locally

Open `index.html` in a browser, or start a local static server from this folder:

```sh
python -m http.server 8000
```

Then visit <http://localhost:8000>.
